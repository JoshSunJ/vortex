Bring your browser into Vortex.

Connect the development extension to see and focus ordinary web tabs. Browser contents are not read by this connection.

  1. Load the extensionOpen Chrome or Edge’s extensions page, enable Developer mode, and load the extension folder.
  2. Allow your extensionCopy its 32-character extension ID into the field below.
  3. Pair locallyCopy the local connection token, paste it into Vortex’s extension options, then choose Save and start.The token stays off this screen. Don’t share or publish it.
  4. Return here and refreshConnected tabs will appear with your app windows.
